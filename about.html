About PrivateFreePdfEditor

PrivateFreePdfEditor is a PDF editor that runs entirely in your web browser. It was built for the everyday jobs people end up paying for, or handing their documents to strangers for: filling in a form by typing on it, signing a contract, blacking out an account number, or deleting a page.

What it can do

  • Add text anywhere, with font, size, style and color
  • Add images and signatures (drawn or typed)
  • Highlight, white out, and draw rectangles, ovals, lines and arrows
  • Find and replace text, and redact it
  • Add page numbers
  • Insert blank pages, remove pages, and reorder them

What it can't do (yet)

  • Edit text that is already in the PDF in place. Find and replace covers the old words with white-out and writes the new ones on top.
  • Open password-protected PDFs.
  • Keep bookmarks or fillable form fields from the original file.
  • Write characters outside the Western (Latin) alphabet in added text. The built-in PDF fonts don't include them.

Built with

PDF.js (Mozilla) shows the pages, and pdf-lib writes the edited file. Both are served from this site, not from a third-party CDN.

Security and privacy

Your document stays on your computer. Here is how that works, and how you can check it yourself.

How your file is handled

  • When you choose or drop a PDF, the browser reads it into memory on your device.
  • PDF.js draws the pages and pdf-lib builds the edited copy, both inside your browser.
  • Download creates the new file in memory and saves it straight to your computer.
  • Closing or reloading the tab discards everything.

What stops the file from being sent anywhere

  • This app has no upload code, and the server has no endpoint that accepts files.
  • Every page is sent with a strict Content Security Policy. It tells your browser to refuse connections to any other website, and to refuse form submissions entirely. The one exception is the online/offline indicator.
  • To show whether you're online, the page sends an empty request to Cloudflare's https://1.1.1.1/cdn-cgi/trace every 2 seconds while the tab is visible. It carries no cookies and nothing about you or your document. The page only checks that the reply is Cloudflare's, so a Wi-Fi login page doesn't count as "online". The reply is not kept or shown.
  • All scripts, fonts and libraries come from this site. Nothing is loaded from a CDN, and there is no analytics, advertising or tracking code.
  • No cookies are set. The only thing stored in your browser is a copy of this app's own files, so it keeps working offline. Your documents are never stored.

Check it yourself

  1. Go offline. Load the home page, turn off Wi-Fi, then open, edit and download a PDF. It all still works.
  2. Watch the network. Open your browser's developer tools (F12), choose the Network tab, and edit a document. You'll see this site's own files and the regular online check to 1.1.1.1, never your file.

About redaction

Covering text with a black box is not enough. Many tools leave the text underneath, where it can be copied out. When you redact here, each affected page is rebuilt as an image with the boxes burned in, so the hidden text is gone. The rest of the text on that page can no longer be selected or searched. White-out is different: it only covers, and the original text is still in the file.

Contribute

PrivateFreePdfEditor is built on open source libraries and is meant to stay free. You can help in a few ways.

Report a problem

If a PDF doesn't open, looks wrong, or saves incorrectly, tell us what you did and what you expected. Please don't send the document itself if it's private. A description, or a similar file without personal details, is enough.

Suggest a feature

Tell us what you'd use it for. Ideas that keep everything in the browser are the ones we can build.

Write code

The editor is plain JavaScript (no build step) on top of PDF.js and pdf-lib, hosted by a small ASP.NET Core app. Good places to start: support for more fonts, filling in existing form fields, and keeping bookmarks when saving.

Spread the word

Next time someone is about to pay for a "free" PDF editor, send them here.
